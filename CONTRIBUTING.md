# Contributing to Ninai

Thanks for your interest in contributing. This project uses a fork-and-PR flow
and maintainers review all changes.

## Quick Start

1. Fork the repo and create a feature branch:
   - `git checkout -b feature/your-change`
2. Make your changes with focused commits.
3. Run tests locally:
   - `python -m pytest backend/tests -v --tb=short`
4. Push your branch to your fork and open a PR.

## Contribution Guidelines

- Keep PRs focused and small.
- Add or update tests for behavior changes.
- Follow existing code style and patterns.
- Document user-facing changes in the PR description.

## Reporting Issues

- Provide clear steps to reproduce.
- Include logs, versions, and environment details.
- Attach screenshots or traces when relevant.

## Code Review

All PRs require maintainer review before merge. Please be responsive to
feedback and update your PR as needed.
