# Support

Thanks for using Ninai Cognitive OS. Here are the best ways to get help:

## Questions and Help

- Use GitHub Discussions for questions, ideas, and troubleshooting help.
- If discussions are not enabled yet, ask a maintainer to turn them on.

## Bug Reports and Feature Requests

- File a GitHub issue using the provided templates.
- Include clear steps to reproduce, expected behavior, and environment details.

## Security Issues

Please do not open public issues for security vulnerabilities.
Follow the guidance in SECURITY.md for private reporting.

## Commercial Support

Enterprise support and managed hosting are available. Email sales@sansten.com
for details.
