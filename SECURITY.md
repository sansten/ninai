# Security Policy

If you discover a security issue, please do not open a public issue.

## Reporting a Vulnerability

Use GitHub Security Advisories to report a vulnerability privately:
- Go to the repository Security tab.
- Click "Report a vulnerability" and follow the prompts.

If you cannot use Security Advisories, contact the maintainers via GitHub
(@sansten) with a brief description and reproduction steps.

We will acknowledge reports and work toward a fix as quickly as possible.
